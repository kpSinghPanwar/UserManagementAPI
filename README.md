# UserManagementAPI

A secure ASP.NET Core Web API that provides user management capabilities with industry-standard API practices.

## Features

- User CRUD operations (Create, Read, Update, Delete)
- JWT Bearer Authentication
- Role-based endpoint protection using Authorize attributes
- Global Exception Handling Middleware
- Request and Response Audit Logging
- Input Validation using Data Annotations
- Duplicate Email Prevention
- Standardized Error Responses
- Swagger/OpenAPI Documentation
- Dependency Injection and Service Layer Architecture
- Serilog File and Console Logging

## Technologies

- ASP.NET Core Web API
- C#
- JWT Authentication
- Serilog
- Swagger/OpenAPI
- Middleware Pipeline
- Dependency Injection

## Security Features

- Token-based authentication
- Protected endpoints
- Request validation
- Consistent error handling
- Audit logging for API requests and responses
